# Plan for fixing vente/location estimation filtering

## Problem
The vente/location filter in the estimation dashboard does not work correctly:
- Both tabs show the same data
- The tab counts are identical
- The Loué tab is missing in location mode
- Retourné, Fournisseur, Livraison tabs should be hidden in location mode

## Solution
Make coordinated changes to filter data and tabs by transactionType (vente/location).

### 1. Layout.tsx (TabNavigation)
- Add `estimationMode?: 'vente' | 'location'` prop to TabNavigationProps
- Filter tabs based on estimationMode:
  - Vente mode: show all tabs (En attente, Traité, Retourné, Fournisseur, Livraison, Archivé, Corbeille)
  - Location mode: show only En attente, Traité, Loué, Archivé, Corbeille
    (hide Retourné, Fournisseur, Livraison; show Loué)
- Add Loué tab to allTabs with appropriate icon (KeyRound) and styling

### 2. EstimationDashboard.tsx
- Pass `estimationMode` prop to TabNavigation component
- In `fetchPage` callback:
  - Derive transactionType: `estimationMode === 'location' ? 'rental' : 'sale'`
  - Pass transactionType to getPaginatedQuotes call
- In `loadInitialData` effect:
  - Pass same transactionType to getQuoteCounts call
- Ensure estimationMode is included in dependencies of useCallbacks where needed

### 3. actions.ts
#### getPaginatedQuotes
- Add `transactionType?: 'sale' | 'rental'` to parameter object
- Add `'transactionType'` to LIST_FIELDS array
- Add `.where('transactionType', '==', transactionType)` to Firestore query when provided
- Map transactionType in returned request objects

#### getQuoteCounts
- Add `transactionType?: 'sale' | 'rental'` parameter
- When transactionType is provided:
  - If effectiveSupplierId exists: add `.where('transactionType', '==', transactionType)` to supplier query
  - Else (admin): perform manual Firestore query with transactionType filter (bypass quote_stats)
- When transactionType not provided: keep existing logic (quote_stats or supplier query)
- Add 'rented' to statuses array to count Loué estimates (since Loué maps to rented status)

## Expected Result
- Vente tab shows only sale estimates (transactionType: 'sale')
- Location tab shows only location estimates (transactionType: 'rental')
- Tab counts reflect correct per-type totals
- Loué tab appears in location mode, Retourné/Fournisseur/Livraison hidden
- No visual changes other than tab visibility and data filtering
